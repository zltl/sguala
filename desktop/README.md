# sguala desktop

Optional Electron UI for sguala. The **primary product is the Go CLI / TUI** at the repository root (`make build`).

```bash
npm install
npm start
npm run make
```

Config: Electron `userData/sguala_2.json`. Passwords and `sguala-bundle` import/export are compatible with the CLI (`internal/secret`, `sguala export|import`).
